# WoodShop 0.16.0

## Download and install
1. Download **WoodShop-0.16.0-macOS.zip** below and unzip it.
2. Drag **WoodShop.app** to Applications.
3. The first time, **right-click the app and choose Open**, then confirm. The app is not notarized by Apple, so macOS blocks a normal double-click on first launch.

**Requirements:** a Mac with Apple Silicon (M1 or later), macOS 14 or newer.

## What's new
- **Imported solids become real boards.** A rectangular block from a SketchUp, STL, OBJ or other 3D file now becomes a board with a thickness, grain along its length, and a species taken from its name (for example "Walnut shelf"). Shaped solids stay as shapes. You can turn this off in the import dialog.
- **Stopped chamfers and roundovers.** Edge profiles can now stop short of the ends of an edge. They follow the board when you resize or turn it.
- **Recognizable hardware.** Hinges, drawer slides, pulls, knobs, corner braces, screws and shelf pins now show as real shapes instead of plain blocks. They are still left out of the cut list and CNC output.
- **Builds on older Swift compilers.** Several long expressions were rewritten so the project builds with Xcode 16.
- **Automated builds.** Every push is built and tested on GitHub, and this release was built and published automatically from the tag.

## Known limits
- SketchUp `.skp` and AutoCAD `.dwg` files are not supported; use DAE or STL from SketchUp and DXF for CAD.
- Only rectangular blocks aligned to the axes are converted to boards on import; rotated blocks stay as shapes.
- The VCarve export has not been verified in every VCarve version. Simulate in VCarve and check units, origin and depths before cutting.
