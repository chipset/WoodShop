# WoodShop 0.15.1

Same app as 0.15.0, now released under the **MIT License**.

- Adds the MIT license (`LICENSE`), included in the download and inside the app bundle
- Adds a README describing the project

## Download and install
1. Download **WoodShop-0.15.1-macOS.zip** below and unzip it.
2. Drag **WoodShop.app** to Applications.
3. The first time, **right-click the app and choose Open**, then confirm. The app is not notarized by Apple, so macOS blocks a normal double-click on first launch.

**Requirements:** a Mac with Apple Silicon (M1 or later), macOS 14 or newer.

Start with [docs/Getting-Started-Workbench.md](https://github.com/chipset/WoodShop/blob/main/docs/Getting-Started-Workbench.md). See the [0.15.0 notes](https://github.com/chipset/WoodShop/releases/tag/v0.15.0) for the full feature list.
